# 🌱 芽メモ / Memonome

日本語のiPhoneメモアプリと、本人のChatGPT利用枠でiPhone／Webアプリを開発・実行・検証するMac連携。MITライセンスで公開しています。

**開発版です。App Storeへ提出済みの1.0とは別のコードです。本人のChatGPTアカウントで接続・Astraの試作品生成を検証済みです。iPhoneのモバイル回線からの同期・自動生成・進捗反映も実機確認済み。チップ商品はApple側で登録準備中です。**

## できること

- AIなし・オフラインでもメモ、検索、お気に入り、バックアップ、24時間以内の削除取り消し。
- ダークモード、ロック画面から新規メモ。
- 自分専用の同期フォルダでiPhoneとMacを接続。送信対象はメモごとに選択。
- 公式Sign in with ChatGPT。Macに保存する認証情報を同期フォルダへ入れません。
- メモからHTML/CSS/JSを生成し、Macの隔離ブラウザで実行・操作テスト。不具合を最大3回修正。進捗と停止・再開をiPhoneに表示。
- 任意のチップ用StoreKit画面。価格はAppleから取得。未登録時は準備中と表示。

自動開発は**SwiftUIのiPhoneアプリとローカルWebアプリ**に対応します。iPhone版はSwiftの実装→Xcodeビルド→XCTestによるシミュレータ操作テスト→不具合修正（最大3回）→実機向け署名・ビルド→指定した接続済みiPhoneへのインストールを行います。85%は接続待ち、90%は実機での本人確認待ち、確認OKで95%です。App Store提出・公開は自動化しません。100%は公開完了です。生成されたビルドスクリプトやシェルコマンドは実行しません。外部依存・購入・広告SDKは追加しません。Web版は隔離ブラウザで確認し、70%で止まります。

## iPhone開発のMac設定
Xcodeと、実機にインストールできるApple開発用署名を用意します。既存のApple Developer契約料は別です。アプリが契約・課金することはありません。ローカル保存先（--localで指定したディレクトリ）のnative-config.jsonに次の設定を保存してください。このファイルには自分の端末情報が入るためGitや同期フォルダに置かないでください。

```json
{"team":"自分の10文字のTeam ID","device":"接続したiPhoneのUDID","simulator":"専用iPhoneシミュレータのUUID"}
```

iPhoneの芽メモ設定で「iPhoneアプリ」を選択します。新規メモは初期設定でiPhoneアプリを作ります。インストール待ちの時はMacに接続してロック解除してください。完了後「試作品を開く」で動作を試し、「iPhoneで試した・確認OK」を押すと確認結果だけをMacに送ります。修正はメモに追記して再開します。TestFlightや外出先へのアプリ配布は未実装です。メモと進捗のiCloud同期は外出先でも可能です。

ビルド・テスト・署名・インストールの完了状態を保存します。同じソースなら再起動後に完了済み段階を飛ばします。テスト中に停止・再起動した場合は未完了のテストを最初から行うことがあります。シミュレータと実機の動作は異なる場合があるため、実機での本人確認が必要です。

## 追加料金への対策と限界

有料APIキー、別プロバイダーへの切り替え、クレジット購入、クラウド容量の購入は実装していません。運営側の常設クラウドサーバーも使用しません。

**ChatGPT設定で、このアプリの「契約枠を超えた後のクレジット使用」をオフにする必要があります。** この設定を照会・強制する公開APIは確認できていません。接続後の確認が終わるまで推論を止めます。あとからChatGPT側で設定を変えた場合まで、アプリ単体で料金ゼロを保証することはできません。既存のChatGPT・iCloud等の契約料金は別です。

- アプリ独自の1日あたりの回数制限はありません。ChatGPTの利用上限で停止します。実行前に依頼を記録し、完了した段階を再送しません。
- 明確なChatGPT利用枠超過エラーだけは依頼を保持し、15分→30分→最大1時間間隔で再試行します（サービス指定の待ち時間が長い場合はそちらを優先）。回復時刻を推測せず、正常に受け付けられた時点で再開します。手動停止・通信中断・認証・保存エラーは自動再開しません。Mac連携の起動が必要です。
- 同期フォルダ5MB、メモ3万文字、生成ファイル30個まで。
- iCloudなどの容量不足はOSが同期を止める場合があります。芽メモがそれを確実に検出できるとは限りません。同期先への書き込み成功はMacへの到着成功を意味しません。
- 同期フォルダを他人と共有しないでください。自分のメモだけを送ってください。

## ソースコードの取得

公開リポジトリの `memonome-source.zip` に、iPhoneアプリ・Mac連携・テストの全ソースを同梱しています。解凍したフォルダで以下を実行してください。

## Mac連携の起動

Python 3.12以降を用意して実行します。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r companion/requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python companion/main.py --sync '/自分専用の同期フォルダ'
```

表示された127.0.0.1のアドレスをブラウザで開き、Continue with ChatGPTで接続。利用設定で追加クレジットを無効にし、モデルを選んで開始します。対応状況は本人のアカウント・ワークスペースによります。

iPhoneの設定 → ChatGPT・Mac連携で、同じ同期フォルダを選びます。「このiPhone内」のフォルダではMacへ同期されません。設定の「新しいメモをAIにおまかせ」をオンにすると、新規メモの保存後に自動送信します。編集画面でも送信のオン・オフを選べます。通信できない間は端末内に送信予約を保持し、アプリの利用中に同じ依頼番号で再送します。AIへのリクエストを自動で繰り返すものではありません。Macの起動が必要です。iPhoneが閉じている間の即時同期は保証しません。停止も同期到着後に反映されます。

Macの認証情報・実行履歴・生成プロジェクトは通常 `~/Library/Application Support/Memonome` に保存します。`--local` で変更できますが同期フォルダの内側/外側に包含させることは禁止しています。実行中は同じローカル保存先を使う複数プロセスをロックします。ログイン情報をGitや同期フォルダに入れないでください。接続解除はChatGPT設定でも行えます。

## iPhoneビルド

`ios/Seed.xcodeproj` をXcodeで開き、自分の開発チームと一意のBundle IDを設定してビルドします。公開コードには開発者個人の署名情報を含めません。

チップ商品IDは `jp.shizuie.memonome.tip.small` / `.medium` / `.large`。すべて消耗型。別アプリとして配信する場合は商品IDも変更し、App Store Connectで設定してください。料金は必ずStoreKitの表示価格を使い、購入は本人のApple確認画面で完了します。機能の購入条件ではありません。

## Mac再起動後の継続

開始・停止と選択モデルはローカルの startup.json に保存します。Mac連携を起動し直すと、開始済みで認証確認済み・エラー停止していない場合に限り自動再開します。手動停止は維持します。利用枠待ちと未処理のメモは継続できますが、画面の構造（index.html）、見た目（style.css）、操作・動き（app.js）を段階ごとにMacへ保存します。再起動後は保存済み段階を飛ばし、未保存の段階だけ自動で再実行します。各段階で利用枠を消費し、途中の段階をやり直す場合も利用枠を使います。追加クレジットへの切り替えはありません。

macOSのLaunchAgentとして登録するとログイン時に起動できます。電源オフ・スリープ・ログイン前は処理しません。認証失効時は再ログインが必要です。追加クレジット使用はオフのままにしてください。
